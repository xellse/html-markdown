# 《一道题长大了：从 7 和 6 走到 i》
## 数论动画系列大纲（v3，6 集，每集约 8 分钟）

> **给家长的一句话说明**：全片只盯一道题："哪些整数能写成'一个平方 ○ 另一个平方'？"中间的符号依次换成减号、"减两倍"、加号。每换一次，整数里的答案就逼我们去找一个更大的"家"：分数、实数（连同极限和微积分的种子），最后是复数。家越来越大，但我们问的始终是整数。

### 2. 一句话核心悬念
4² − 3² = 7 一下就找到了，6 却怎么也找不到。是还没找到，还是永远不可能？把"减"换成"减两倍"、再换成"加"，同一道整数题一次次撑破手里的数：要多大的"家"，才装得下它的答案？

| 2 | 不用试遍所有数 | 按 4 分组（余数门）：平方只余 0 或 1，所以平方差永远不余 2。用一个理由排除无穷多个数（完整反证）。 |

| 6 | 加号要转个弯 | a² + b²：余数门排除余 3 的数；因子门要把它拆开，需要一个平方等于 −1 的数，于是有了 i 和复数；两个平方和相乘还是平方和。 |

**两扇门的分工（Jasper 最后要能用自己的话说出来）**
- **因子门**（看一个数是谁乘谁）：负责**构造**和**找全**，也能排除。出现在第 3 集的同奇偶因子对和一一对应、第 5 集延伸里的 (a/b − √2)(a/b + √2)、第 6 集的 (a+bi)(a−bi) 与平方和乘法。
- **余数门**（按某个数分组，看剩下多少）：负责**排除**，它只说出"必须满足的条件"。出现在第 2 集的"平方差不余 2"、第 4 集的"分数的小数必停或循环"、第 6 集的"平方和不余 3"。
- **两门相遇**（两条独立的路走到同一个结论）：第 3 集，两扇门各自证出"余 2 不行"；第 4 集延伸，剪纸证明和奇偶证明证出同一件事。
- **大小关系**：第 3 集"b 最多到 (N−1)/2，只有有限个可能"；第 4 集"越剪越小"，即最小反例；第 5 集"误差是 1/b²"。

**极限和微积分的位置**
- **极限**（第 5 集主线）：无穷多组 ±1 解给出一串分数。要说清它们"越来越准"准到哪里，就要用误差游戏来定义极限；而只有分数的数轴在那里有个洞，所以需要实数。
- **导数的种子**（第 5 集主线）：第 1 集的奇数边带 = 两条臂 + 一个角。第 5 集给正方形加一条细边带来改进近似值；边带越窄，那个角越不重要，面积随边长变化的快慢就是 2x。
- **积分的种子**（第 6 集延伸，**建议保留**）：数半径 10 的圆里的整数格点，共 317 个，和面积 100π ≈ 314 对照。数小方块就是在量面积。

**数系表述规范（遵守创作说明第五节，全片统一）**
- 小数是一种**写法**，不是一类新的数：3.5 和 7/2 是同一个数。
- 有理数：能写成 p/q 的数（p 是整数，q 是正整数）。整数也能写成分数的样子（5 = 5/1），所以整数也是有理数。
- 无理数：**不能写成两个整数之比的实数**，它的标准十进制展开既无限又不循环。不说成"开根号得到的数"：√4 = 2 是有理数；π 是无理数，却不是开根号来的。
- 实数：数轴上所有的点对应的数，包括整数、分数和无理数。"数轴没有洞"是数学家给实数定下的**基本规则**，不是本片证明的定理。
- 复数：a + bi，a、b 是实数，i × i = −1。b = 0 时就是实数，所以实数包含在复数里。b ≠ 0 的才叫虚数，**不把复数统称为虚数**。
- 负数：第 1–3 集只用 0 和正整数（"负数以后再说"；第 2 集遇到不够减就借位，不写出 −1）。第 4–5 集让 −1 以"少了 1"的身份出现在数轴上，不做负数乘法。第 6 集再讲清 (−1) × (−1) = 1 的理由。

每集 1–2 处，每处一两句话，都用来给推理帮忙。只引用已经核实过的内容，只说到"漫士讲过……"这个程度，不编原话。我们自己补充的话由旁白另起一句说。Jasper 看过的 5 期全部用上，见文末附表。

### 本集完整演示的不跳步推理
1. 一个 n×n 点阵（n 是 0 或正整数，n = 0 时什么都没有），外面包一层，变成 (n+1)×(n+1)。
2. 多出来的点：右边一列 n 个，上边一行 n 个，右上角 1 个，一共 2n + 1 个。这个数法不依赖 n 是几，所以对每个 n 都有 (n+1)² − n² = 2n + 1。
3. 反过来，任给一个正奇数 N，N − 1 是 0 或正偶数，所以 n = (N−1)/2 是 0 或正整数（N = 1 时 n = 0）。
4. 代入第 2 步：(n+1)² − n² = 2n + 1 = N。
5. 结论（带范围）：每个正奇数 N 都能写成 ((N+1)/2)² − ((N−1)/2)²，两个数都是 0 或正整数。这一步覆盖**所有**正奇数，不是试出来的几个。

- 正整数，以及"0 或正整数"：第一次出现时画在数轴上。
- 平方差 a² − b²：本集范围是 a > b，a、b 为 0 或正整数。
- 正奇数：除以 2 余 1 的正整数，即 2n + 1。
- 本集不命名任何"大名词"。

### 本集完整演示的不跳步推理（反证）
1. 假设有 0 或正整数 a > b，使 a² − b² = 6。
2. 由上一拍，可以写 a² = 4u + r，b² = 4v + w，其中 u、v 是 0 或正整数，r、w 都只能是 0 或 1。
3. 相减：四个一组的部分相减，还是四个一组；零头 r 和 w 相减，只有四种情况：0 − 0、1 − 1 得 0，1 − 0 得 1，0 − 1 不够减。
4. 不够减时，借一组 4：4 + 0 − 1 = 3，也就是余 3。
5. 所以平方差除以 4 只能余 0、1 或 3，**永远不余 2**。
6. 6 = 4 × 1 + 2，余 2，矛盾。所以不存在这样的 a、b。
7. 第 2–5 步没有用到"6"的任何特点，只用了"a > b，都是 0 或正整数"，所以这个结论对**每一个**除以 4 余 2 的正整数都成立。

### 本集完整演示的不跳步推理
**第一部分：同奇偶，两个方向分开证**
- **必须（必要）**：如果 a、b 是整数，s = a − b，t = a + b，那么 t − s = 2b 是偶数。两个整数相差偶数，奇偶就相同，所以 s、t 同奇偶。
- **足够（充分）**：设 s ≤ t 是同奇偶的正整数，s × t = N。令 a = (s + t)/2，b = (t − s)/2。同奇偶保证 s + t、t − s 都是偶数，所以 a、b 是整数；t ≥ s 保证 b ≥ 0；a − b = s ≥ 1 保证 a > b；并且 a² − b² = (a − b)(a + b) = s × t = N。

**第二部分：一一对应（不漏、不重）**
1. **写法 → 因子对**：任给一种写法，令 s = a − b，t = a + b。因为 a > b，s ≥ 1；因为 b ≥ 0，t ≥ s；剪拼给出 s × t = N；第一部分给出 s、t 同奇偶。所以**每一种写法都来自某个同奇偶因子对**，没有漏网的写法。
2. **因子对 → 写法**：就是第一部分的"足够"。
3. **来回一趟回到原处**：由 (a, b) 算出 (s, t)，再算 (s + t)/2 = a、(t − s)/2 = b，回到原来的写法。所以不同的写法给出不同的因子对，不会重复。
4. 结论：N 的写法个数 = N 的同奇偶因子对（s ≤ t）个数。因子对只有有限个，可以系统地列出来，所以写法能找全。

### 新概念与符号
- 因子、因子对 s × t：s、t 是正整数，约定 s ≤ t，避免把 1×45 和 45×1 算成两个。
- 同奇偶：两个数同为奇数或同为偶数，也就是它们的差是偶数。
- "当且仅当（⇔）"：两个方向都证完以后才使用。
- 有理数（分数）p/q：p 是整数，q 是正整数；整数也能写成分数的样子，所以也是有理数。
- 小数：一种写法。3.5 和 7/2 是同一个数，就像同一个点贴了两张标签。

### 数系从哪里长出来
"足够"那一步要除以 2。因子对不同奇偶时除不尽，7/2、5/2 就掉了出来。分数不是被介绍进来的，而是在解 a = (s + t)/2 时被除法逼出来的。结尾指出因子门卡住的地方：2b² 在整数里不是平方，这扇门打不开。

### 本集完整演示的不跳步推理（最小反例 + 剪纸）
1. 假设有正整数 a、b 满足 a² = 2b²。在所有这样的解里，挑 a 最小的一组。
2. 比大小：a² = 2b² > b²，所以 a > b；a² = 2b² < 4b² = (2b)²，所以 a < 2b。
3. 在 a×a 的正方形里，把两个 b×b 的正方形分别压在左下角和右上角。
4. 两个小正方形的面积合起来是 2b² = a²，正好等于大正方形的面积。它们重叠出一块边长为 2b − a 的正方形（由第 2 步 a < 2b，这条边是正整数）；同时留下两个没盖到的角，各是边长为 a − b 的正方形（a > b，也是正整数）。
5. 面积一样大，所以重叠时多算了一次的那块，必须正好等于没盖到的两个角：(2b − a)² = 2(a − b)²。
6. 这是一组新的正整数解，而且 2b − a < a（因为 b < a）。这和"a 最小"矛盾。
7. 所以不存在这样的正整数 a、b。也就是说，**没有任何正分数的平方等于 2**（负分数的平方和对应正分数的平方一样，留到第 6 集讲清楚）。

- √2：平方等于 2 的正数，本集作为单位正方形对角线的长度出场；"它作为一个数一定存在"的理由在第 5 集给出。
- 无理数：不能写成两个整数之比的数，它的标准十进制展开无限而且不循环（第 5 集正式说"实数"后再精确一遍）。
- 最小反例：用完之后命名。
- 循环小数：用"…"表示，循环部分上方画一条弧线；y 只在这里和第 5 集指循环小数。
- −1：画在数轴上 0 的左边，只作为"少了 1"的记号。

### 数系从哪里长出来
"a² 能不能等于 2b²"是一道纯粹的整数方程，答案是"不能"。这个"不能"说明对角线和边的比不是任何分数，于是数轴上出现了一个"分数够不着的位置"，也就是无理数。接着，余数门说清了分数的小数为什么必停或循环；再加上反方向"停或循环的小数都是分数"（还欠着一张欠条），就能推出 √2 的小数不停也不循环。

### 本集完整演示的不跳步推理（展开 + 归纳）
1. (a + 2b)² = a² + 4ab + 4b²。
2. 2(a + b)² = 2a² + 4ab + 2b²。
3. 相减：(a + 2b)² − 2(a + b)² = 2b² − a² = −(a² − 2b²)。
4. 起点 (1, 0)：1 − 0 = +1。每爬一级，值变成相反数，大小不变：+1 → −1 → +1 → …，所以每一级都满足 a² − 2b² = ±1。
5. 新的 b 等于 a + b，比原来的 b 大（因为 a ≥ 1），所以 b 每一级都严格变大，各组解两两不同。从 (1, 1) 起都是正整数解，因此有**无穷多组**。

### 新概念与符号
- ±：正或负。
- 数学归纳法：证完之后命名。
- 极限：用"对手报任何正误差，我都能找到一级，从那以后全都比它近"来定义。
- 实数：数轴上所有点对应的数。**基本规则**：一层套一层、宽度要多窄有多窄的夹子恰好夹住一个点（明说这是规则，不是定理）。
- 无理数（准确版）：不是有理数的实数。
- 导数（只作为种子命名）：面积随边长变化的快慢，等于 2 × 边长；不出现 dy/dx 这类符号。

### 数系与极限、微积分从哪里长出来
- 整数问题"±1 有没有无穷多组解"：有，由爬楼梯机器加归纳证明。
- 这无穷多组解变成一串分数。要说清它们"越来越准"准到哪里，就需要**极限**。
- 它们逼近的地方不是分数（第 4 集），只有分数的数轴在那里有个洞，所以需要**实数**和"夹子规则"。
- 在实数里，因子门以 (a/b − √2)(a/b + √2) 的样子重新打开，说明分数串本身逼近 √2（延伸 A′）。
- 想更快地逼近，就从第 1 集的"边带 = 两条臂 + 一个角"里长出**导数**的想法。

- **C. 爬一级 = 乘一次 (1 + √2)（约 30 秒）**：(a + b√2)(1 + √2) = (a + 2b) + (a + b)√2，正好就是爬楼梯的机器。旁白："下一集里，(a + bi)(a − bi) 就是这里 (a − b√2)(a + b√2) 的兄弟。"

### 本集完整演示的不跳步推理（平方和 × 平方和 = 平方和）
范围：a、b、c、d 是整数。

(ac − bd)² + (ad + bc)²
= (a²c² − 2abcd + b²d²) + (a²d² + 2abcd + b²c²)
= a²c² + a²d² + b²c² + b²d²
= a²(c² + d²) + b²(c² + d²)
= (a² + b²)(c² + d²)

画面上，两块交叉项 −2abcd 和 +2abcd 一正一负，正好抵消。这恰好是复数乘法 (a + bi)(c + di) = (ac − bd) + (ad + bc)i 在整数上的影子：复数一乘，就自动把两个平方和"乘"到了一起。数字检验：a = 1、b = 2、c = 2、d = 3 时，(2 − 6)² + (3 + 4)² = 16 + 49 = 65 = 5 × 13。

### 新概念与符号
- (−1) × (−1) = 1：用分配律给出理由，再推到"负数乘负数是正数"；"转半圈两次"只是画面上的解释。
- i：规定 i × i = −1，画面上的意思是"转四分之一圈"。
- 复数 a + bi：a、b 是实数；实数包含在内（b = 0）；虚数指 b ≠ 0 的复数。
- 费马平方和定理：只陈述，注明本片不证。
- （可删屏幕卡片，可以不读）完整判别：正整数能写成两个平方的和，当且仅当它每个"除以 4 余 3"的质因数都出现偶数次。例如 45 = 3 × 3 × 5，3 出现两次，所以 45 = 36 + 9。（只陈述，不证明。）
- 不命名"高斯整数"，正文直接说"a、b 都是整数时"。

### 数系从哪里长出来
因子门想把 a² + b² 像 a² − b² 一样拆成两个因子，这需要一个平方等于 −1 的数。实数里没有，于是在平面上用"转弯"造出了 i，复数就这样被逼了出来。复数在这里的用处，是证明一个纯整数的事实："两个平方和相乘，还是平方和。"
