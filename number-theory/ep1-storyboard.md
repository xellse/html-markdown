# 《一道题长大了》第 1 集《7 找到了，6 呢？》分镜与台词

**本集唯一的核心问题**：哪些正整数能写成两个平方的差？先回答其中一块：**是不是每一个正奇数都能？**

**一句话**：4² − 3² = 7 一下就找到了，6 却怎么也找不到。我们一层一层包点阵，发现多出的一圈总是奇数，再用一个"不管 n 是几都成立"的数法，两个方向都证明：每一个正奇数都是两个平方的差。偶数呢？Jasper 猜"偶数都不行"，自己找到 4、8、12 把它推翻。表里还空着 2、6、10、14……这串数有无穷多个，查不完，下一集要找一个对这串里每一个都成立的理由。

**时长**：按配音语速公式估算约 8 分 37 秒（包括给画面留的停顿），另有一处可暂停的"轮到你了"。

**角色**
- **旁白**（云希）：讲故事的大哥哥，用"我们"，和 Jasper 一起检查，不当裁判。
- **Jasper**（孩子配音）：书桌前的火柴人，接《数学少年陶哲轩》第 6 集结尾的那张书桌。他算得快，会猜，会自己发明记号，也会猜错。
- **小问号**（红色问号小人）：陶哲轩系列结尾跳到 Jasper 身边的那个小问号。它只问问题："然后呢？""0 算不算？""第一百层也是吗？"，弄懂了就开心。

**全片约定（本集起沿用）**
- 黑墨表示世界和推理；红笔表示批注、核对和小问号；黄色荧光笔标关键结论，一个画面最多一两处。
- **范围卡片**：白色小卡片，用图钉钉在结论旁边，写明"两个数是 0 或正整数……"。
- **地图**：开场出现，之后每集开头和结尾回到地图，看走到了哪一级台阶。它代替陶哲轩系列里的年龄印章，作为时间线的锚点。
- 数学符号先有画面，再出现：先画 4×4 点阵，再写 4²；先画边上的点，再写 n。
- 名词在用到时才解释，并配一个画面："猜想"（牌子上的标签）、"反例"（4 旁边的标签）、"0 或正整数"（一小段数轴）。
- 用词分开：Jasper 的**记号** ┐ 指"能写成两个平方的差"；相邻两个平方之间的**一圈**由"两条胳膊 + 一个角"组成。粗一点的拐角（如 8 = 3² − 1²）也能打记号，但它不是"一圈"。

**事实与引用**：本集唯一的真实事件是漫士沉思录那期（BV1G7jJ6nEbV，2026 年 6 月）讲的"数学家们猜了八十年的一个说法，被一个反例推翻"（埃尔德什 1946 年提出的平面单位距离猜想，2026 年被推翻）。片中只说到这一层，不提猜想名字，也不画漫士本人。其余都是数学，所有算式都已用程序验算。

## 3:10–5:08 · 每一个正奇数（一般的 n、反过来造 99）

**画面**

- 画一个没有具体大小的正方形：四角画点，中间用“…”表示省略，两条边上写 n（“每条边上有 n 个点”）。旁边滚动显示“n = 0、1、2、100……”。
- 外面包一层：右边一列先亮（标 n），上边一行再亮（标 n），角上最后亮（标 1），新正方形的边上标 n+1。
- “大正方形减掉原来的正方形”：手写 (n+1)² − n² = n + n + 1，每写一项，笔尖都指向对应的点阵：(n+1)² 指大正方形，n² 指原来的正方形，n、n、1 指两条胳膊和角。
- “两两配对，多出的 1 落了单”：右列和上行的点用短线一对一对连起来，角上那个点孤零零地晃一下。黄色荧光笔写：总剩一个的数，就是奇数。
- “不管 n 是几都一样”：n 的值继续滚动，图形跟着变大变小，数法不变。
- 小问号举牌“那反过来呢？随便给一个奇数，都能做成这样的一圈吗？”
- 99 个点堆成一堆 → 先拿出落单的 1 个放在角上 → 剩下 98 个分成两条胳膊，各 49 → 两条胳膊包住一个 49×49 的正方形（画成示意，中间省略；胳膊的长度和正方形的边用同一个数字 49 标出）→ 变成 50×50。
- 红笔在旁边竖式核对：50×50 = 2500，49×49 = 2401，2500 − 2401 = 99 ✓。
- “任何奇数都能这样”：3、5、7、9 依次拆开：拿掉落单的 1 个、剩下的分成两条胳膊、包住一个正方形、补成大一号的正方形，每个都用红笔标出“大 − 小”。
- “就连 1 也行”单独演：1 个点拿掉落单的那个后什么也不剩，两条胳膊是空的，包住一个 0×0 的“空正方形”：1 = 1² − 0²。
- 结论用黄色荧光笔写出，旁边逐个亮起 1、3、5、7……，范围卡片钉在一旁：**每一个正奇数，都是两个平方的差**（两个数是 0 或正整数）。

## 制作备注（进入制作时再细化）
- **新引擎组件**：可伸缩的点阵（n×n，大的时候中间画省略号）、"一圈"高亮（胳膊实线、角上虚线圈）、点的配对连线、纸带数轴、地图（两扇门、台阶、雾）、范围卡片（图钉）加小数轴。
- **手写字形**：`write` 的 GLYPH 里没有 ²、n 和 ┐。² 和 n 要补进 GLYPH；┐ 做成自定义 PROPS 小图标（不用 highlight、ring）。`write` 里的减号一律用 ASCII 的 `-`（分镜里显示为 −），GLYPH 不认识的字符会被直接跳过、不报错。
- **镜头**：引擎没有镜头推拉。开场"本子变地图"用翻页切换；"回到练习本"直接切场。需要放大时用整页道具加缩放补间。
- **复用素材**：第 6 集的 Jasper 书桌（`e6_desk`）和小问号（`qm`）直接接过来。
- **配音试听**（生成配音后先听这几句）："两个平方的差"的"差"要读 chā，读错就把 say 改成"两个平方之差"；"Jasper"和字母 n 由中文声音念，听着别扭的话请你试听后再定（也可以改成"他的练习本"）；"这样算"已经避开了多音字"数"。
