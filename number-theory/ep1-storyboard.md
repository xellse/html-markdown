# 《一道题长大了》第 1 集《7 找到了，6 呢？》分镜与台词

**本集唯一的核心问题**：哪些正整数能写成两个平方的差？先回答其中一块：**是不是每一个正奇数都能？**

**一句话**：4² − 3² = 7 一下就找到了，6 却怎么也找不到。我们一层一层包点阵，发现多出的一圈总是奇数，再用一个"不管 n 是几都成立"的数法证明：每一个正奇数都是两个平方的差。偶数呢？"偶数都不行"的猜想被 4、8、12 推翻；剩下的空格 2、6、10、14……有无穷多个，查不完，下一集要找一个对所有空格同时成立的理由。

**时长**：按配音语速公式估算约 7 分 57 秒，另有一处可暂停的"轮到你了"。

**角色**
- **旁白**（云希）：讲故事的大哥哥，用"我们"，和 Jasper 一起检查，不当裁判。
- **Jasper**（孩子配音）：书桌前的火柴人，接《数学少年陶哲轩》第 6 集结尾的那张书桌。他算得快，会猜，会自己发明记号，也会猜错。
- **小问号**（红色问号小人）：陶哲轩系列结尾跳到 Jasper 身边的那个小问号。它只问问题："然后呢？""0 算不算？""第一百层也是吗？"，弄懂了就开心。

**全片约定（本集起沿用）**
- 黑墨表示世界和推理；红笔表示批注、核对和小问号；黄色荧光笔标关键结论，一个画面最多一两处。
- **范围卡片**：白色小卡片，用图钉钉在结论旁边，写明"两个数是 0 或正整数……"。
- **地图**：开场出现，之后每集开头和结尾回到地图，看走到了哪一级台阶。它代替陶哲轩系列里的年龄印章，作为时间线的锚点。
- 数学符号先有画面，再出现：先画 4×4 点阵，再写 4²；先画边上的点，再写 n。

**事实与引用**：本集唯一的真实事件是漫士沉思录那期（BV1G7jJ6nEbV，2026 年 6 月）讲的"一个猜了八十年的数学说法被一个反例推翻"（埃尔德什 1946 年提出的平面单位距离猜想，2026 年被推翻）。片中只说到这一层，不提猜想名字，也不画漫士本人。其余都是数学，所有算式都已用程序验算。

## 2:58–4:39 · 每一个正奇数（一般的 n、反过来造 99）

**画面**

- 画一个没有具体大小的正方形：四角画点，中间用“…”表示省略，两条边上写 n（“每条边上有 n 个点”）。旁边滚动显示“n = 0、1、2、100……”。
- 外面包一层：右边一列先亮（标 n），上边一行再亮（标 n），右上角最后亮（标 1）。手写：n + n + 1。
- “两个 n 配成对，多出的 1 落了单”：右列和上行的点两两连成一对一对，角上那个点孤零零地晃一下。
- “不管 n 是几都一样”：黄色荧光笔划过这句话，n 的值继续滚动，图形跟着变大变小，数法不变。
- 小问号举牌“那反过来呢？随便给一个奇数，都能做成小拐角吗？”
- 99 个点堆成一堆 → 先拿出一个放在角上 → 剩下 98 个分成两排，各 49 → 两排像两只手臂一样包住一个 49×49 的正方形（画成示意，中间省略）→ 变成 50×50。
- 红笔在旁边竖式核对：50×50 = 2500，49×49 = 2401，2500 − 2401 = 99 ✓。
- “任何奇数拿掉一个都是偶数”：一串奇数 1、3、5、7、9……依次拿掉角上的一个、平分成两臂。轮到 1：拿掉角上一个后什么也不剩，两臂是空的，包住一个 0×0 的“空正方形”：1 = 1² − 0²。
- 结论用黄色荧光笔写出，范围卡片钉在旁边：**每一个正奇数，都是两个平方的差**（两个数是 0 或正整数）。

## 本集对照创作说明的验收项
| 验收项 | 本集在哪里 |
|---|---|
| 先给整体，再回到小步骤 | 开场地图（两扇门、五级台阶、雾） |
| 至少一次猜想被检查 | "偶数都不行"被 4、8、12 推翻；"每隔 4 个就有一个不行"贴上"还没证明" |
| 至少一段没有跳步的证明 | "每一个正奇数都是两个平方的差"：一般的 n 加反方向的构造，覆盖所有正奇数，包括 1 |
| 区分"试了很多个"和"对所有情况成立" | 三层点阵对比一般的 n；电脑查到 1000 对比"无穷多个" |
| 新符号有定义 | 4² 先画 4×4 点阵；n 先指着边上的点；Jasper 的小拐角记号被要求说清规则 |
| 结论写明范围 | 范围卡片：0 或正整数，前大后小，后一个可以是 0；负数以后再说 |
| 旁白不当裁判 | 猜错由小问号提问、旁白提议"我们找找它会不会在别处失败"，Jasper 自己发现反例 |
| 留下继续探索的愿望 | 空格到底是"还没找到"还是"根本没有"，留到下一集 |
