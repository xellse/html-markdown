# 画面、动效、声音规范

目标是让 Ben Orlin 那种"画得不好但很自信"的火柴人漫画动起来。下面的数值都已写进引擎（`src/engine.js`），这里说明它们为什么是这样，改动时要保持的原则。

## 1. 舞台与纸
- 内部坐标 **1600 × 900**（16:9），SVG `viewBox`，随页面缩放。
- 纸色 `#FBF8F1`，不随深色模式变化。深色模式只改变纸外面的"桌面"颜色。
- 地面是一条浅灰铅笔线，默认 y = 780，每个场景可以用 `floor` 自己设定。
- **字幕带在 y 800–880**，重要的画面都放在 y 790 以上。

## 2. 颜色（颜色即意义，见 narrative.md 3.1）
| 名称 | 色值 | 只用于 |
|---|---|---|
| 墨 ink | `#1E1E1E` | 世界、人物、主角写的字 |
| 红笔 red | `#D23A3F` | 旁白批注、箭头、验算 ✓、印章、小问号 |
| 荧光黄 hi | `#FFE066`（叠加 multiply，透明度 0.85） | 关键知识，每个画面最多 1–2 处 |
| 铅笔灰 pencil | `#9B9B9B` | 地面、阴影、横线、灰尘 |
| 纸 paper | `#FBF8F1` | 背景和所有填充 |

不要引入新颜色。确实需要第五种颜色（比如奖牌金）时，只给一个意义，并写进系列规范。

## 3. 线条
- **笔触**：圆头圆角，人物线宽 5.5–6，道具 4–5，细节 2–3.5。数值是舞台单位，随缩放变化。
- **手绘感分两层**：
  - 静态歪斜：`WOBBLE 1.4`，按每条线的 key 固定，同一条线每一帧形状一样。
  - 线条抖动（line boil）：每秒换 5 次形状（`BOIL_FPS 5`），幅度 `BOIL_AMP 1.1`。
  - 抖动由时间决定，同一时刻永远是同一幅画面。
  - 系统开启"减少动态效果"时，关闭抖动。
- **两点直线会自动微微弯曲**，像手画的。
- **绘制出现**：场景道具 0.38 秒"画出来"，多笔的道具按笔顺依次画（`stag`）。

## 4. 人物造型（角色设定）
Orlin 构造法：
- 圆头略不规则；
- 眼睛是椭圆，里面一个黑点瞳孔；
- 眉毛一笔，嘴一笔；
- 身体和四肢都是单线，手脚不画手指；
- 脚下有铅笔涂的小阴影。

| 参数 | 成人 | 孩子（kid: true） |
|---|---|---|
| 身高 H | 380–440 | 150（2 岁）… 240（7 岁）… 255（9 岁） |
| 头 head（占 H 的比例） | 0.36–0.42 | 0.43–0.52（年龄越小头越大） |
| torso / leg / arm | 0.22–0.25 / 0.30–0.33 / 0.34–0.36 | 0.22 / 0.30 / 0.34 |

- **用一个特征认人**：主角用一撮翘起的头发（`tuft`），全系列不变。配角各有一个特征：眼镜、领带、马尾（`ponytail`）、卷发（`curly`）、齐耳短发（`bob`）、地中海加侧发（`sides`）、中分（`part`）、乱发（`messy`）。
- **表情库**：neutral、smile、grin、joy、proud、proudGrin、focus、idea、surprised、puzzled、bored、jaw（下巴掉了）、sheepish、effort、laugh。表情全靠眼睑、眉毛角度、嘴形组合出来。
- **小问号**：红色问号形身体，眼睛和嘴在问号的弯钩里，两条小腿，可以举牌。心情有 neutral、happy（弯眼加腮红）、doubt、surprised；动作有 hop、nod、tap（跺脚）、wave、shake。
- **孩子的手臂短**，大头会挡住举起的手。欢呼、挠头、托腮要用加长手臂的版本：`kidCheer`、`scratchStand`、`thinkStand`（`armScale` 1.5–1.75）。

## 5. 文字与字体
- 中文：**ZCOOL KuaiLe**（站酷快乐体），手写感强，对孩子友好。
- 英文和数字标签：**Patrick Hand**。
- 站酷快乐体把拉丁字母 O 画成方块（"IMO"会读成"IM口"）。所以引擎的 `text()` 遇到含英文字母的字符串，会自动改用 `CFG.FONT_MIX`（Patrick Hand 优先，中文仍是站酷）；字幕也一样。数字仍用站酷字体，和前几集保持一致。
- 电脑屏幕和代码：**VT323**（复古终端字体）。
- 数学式子不用字体，用引擎自带的**单笔手写字形**（GLYPH），支持 0–9 x + - × ÷ = ≠ < > ✓ , . ? □ ( ) … →，一笔一笔写出来。
- 字号（舞台单位）：

| 用途 | 字号 |
|---|---|
| 字幕 | 52，带纸色描边 |
| 红笔标签 | 40（第二行 ×0.82） |
| 对白 | 56–84 |
| 片名 | 120–140 |
| 小知识卡标题 | 78 |

- 手机宽 390 像素时，舞台缩到约 0.24 倍，所以正文字号不要低于 36。

## 6. 构图与层级
- **层级（z）**：set 10 → 黄色高亮 12 → 黑板 14 → 阴影 18 → 椅子 20 → 背包 28 → 身体 30 → 桌子 35 → 手臂和头 40 → 特效 50 → 红笔标注 60 → 印章 70 → 字幕 90。
  - 盖住画面的道具（报纸、小知识卡），取 55 左右。
  - 印在道具上的人物，用 `def.z` 整体抬高层级。
- **一个画面一个焦点**。标签不要压在脸上，箭头从标签框边缘出发，停在目标前 6–16 单位。
- **印章**停靠在右上角 (1486, 108)，缩放 0.46；系列名在左上角 (40, 44)。

## 7. 动效
这里不追求流畅的补间，追求的是"漫画活过来"。
- **有限动画**：姿势快速切换（0.07–0.15 秒，常用 `back` 缓动，带一点过冲），然后停住。停住才有漫画感。
- **挤压拉伸**：落地、惊讶时 `squash` 0.86–1.14，0.2–0.3 秒弹回。
- **入场**：人物"弹出"（0.3 秒 back）；标签 0.2 秒弹出，箭头 0.3 秒画出；小问号出场可以带墨线爆开的效果（`burst`）。
- **走路**：`makeWalk` 两拍一步，约 5.2 Hz，头发跟着速度摆动。
- **写字速度**：黑板上约 2300 单位/秒，红笔验算 2800–3200。
- **视线**：`gaze` 让眼珠看向目标。看同一个东西的人，眼珠要真的对准它。
- **眨眼**：每个角色的周期不同（3.3–4.4 秒），避免大家同时眨。
- **转场**：直接切，下一场景的道具在 0.4 秒内画出来。长场景中途切画面时，旧的道具设 `t1` 让它消失。
- **停留**：每个反应至少停 1.5 秒，标签停 1.5–4 秒。

## 8. 声音
### 配音
- **旁白**：`zh-CN-YunxiNeural`（云希，年轻男声），语速 +5%。
- **主角台词**：`zh-CN-YunxiaNeural`（云夏，男孩声）。
- **小问号**：云希，语速 +8%，音调 +30Hz。
- **女孩主角**：可以用 `zh-CN-XiaoyiNeural`（晓伊，活泼的年轻女声），语速 +0%。在 meta.json 的 `audio.voices` 里加一个 `girl`，台词写 `voice: 'girl'`。换声音后先生成一句试听，让用户确认。
- 每一行字幕生成一段音频，打包进 `episode-N.audio.js`，播放时对齐字幕。
- **旁白说话时画面不会跑到下一句**：播放器在下一句开始前等配音说完。时长按 narrative.md 第 6 节的公式留，一般用不到这个等待。
- 拖动进度条时，会从当前句子的中间接着说。

### 配乐（Kevin MacLeod，CC BY 4.0，已附在模板里）
| 名称 | 曲子 | 用在 |
|---|---|---|
| main | Carefree（尤克里里 + 马林巴） | 讲故事、片头、片尾 |
| chip | Bit Shift（8-bit） | 电脑、编程、游戏 |
| calm | Easy Lemon（钢片琴，适合垫旁白） | 小知识卡、推导、证明 |
| sneaky | Investigations（俏皮拨弦） | 小问号、侦探感、反例 |
| turn | Life of Riley（钟琴 + 尤克里里） | 轮到你了、方法总结 |
| think | Local Forecast - Elevator（电梯等候音乐） | 互动停顿时等孩子想 |

- 在 `meta.json` 里给每个场景指定一首。连续几个场景用同一首时，音乐不会重新开始。换曲时淡出淡入 0.7–0.8 秒。
- 音量：音效 0.45，人声 1.0，音乐 0.3；有人声时音乐压到 0.11。
- 页面底部自动生成署名（CC BY 的要求）。
- 其他学科可以换曲子（例如古诗用古筝），务必确认授权，并在 `tracks` 里写 `author` 和 `license`。

### 音效
引擎用 WebAudio 合成，没有音频文件：
- 常用：pop、plip、boop、pen、chalk、stamp、whoosh、whip、swish、thud、hop、zip、ding、boing、tada、paper、tap、step；
- 电脑相关：key、beep、buzz。
- 用 `SFX.define` 可以加新的。音效要短（< 0.3 秒），只在画面上有动作时响。

## 9. 页面外壳（播放器）
- 纸（舞台）放在"桌面"上，下面是播放条：播放/暂停、从头播放、进度条、时间，以及"配音""音乐""音效"三个开关，偏好记在浏览器里。
- 播放条下面是**章节按钮**，每个带 `chapter` 的场景一个。再下面是颜色图例，最后是署名。
- **封面帧**：页面打开时，显示本集最有代表性的一帧，中间一个大的播放按钮（`meta.poster`）。
- 空格键播放/暂停；标签页被隐藏时自动暂停；手机宽度下进度条换到单独一行。
