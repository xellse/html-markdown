# 叙事语言：用火柴人把一个道理讲进孩子心里

这份文档说明"讲什么、怎么讲"，不涉及怎么画。它来自《数学少年陶哲轩》系列：给一个 8 岁、数学很深但心智仍是孩子的观众，讲陶哲轩从"一眼看出来"到"学会写清楚"的故事。这些规则不限于数学，任何"一个人（或一个概念）怎样一步步想明白一件事"的题材都适用。

## 1. 核心理念

- **一集只讲一个核心道理。** 例如"看出来 ≠ 证出来"。所有场景都为它服务，别的内容放到下一集。
- **故事和知识拧在一起。** 知识不作为插播，而是故事的转折点：人物卡住了，靠这个知识走出来。
- **知识不降级，讲法童趣化。** 聪明的孩子能接受真正的证明，比如奇偶证明、快乐数的完整证明、极限的直观。难的是语气和节奏：一句话一个意思，道理交给角色和画面去"演"，不念给孩子听。
- **角色有情绪弧线。** 固定配角（小问号）从"烦人"到"朋友"，最后变成主角脑子里的习惯。情绪变化让道理被记住。
- **诚实。** 真实的事有出处；演绎要让大人一眼能分辨（见第 7 节）。孩子会信你说的每一句话。

## 2. 观众画像：先定这个，再动笔

开工前问清楚（或从对话里整理出来），写进项目的大纲文件：

| 问题 | 影响什么 |
|---|---|
| 年龄、心智阶段 | 句长、每集时长、笑点类型、要不要互动停顿 |
| 知识深度、在读什么书 | 题目难度，能不能提"极限""证明""递归"，可以回调哪些书 |
| 性格特点（例如"脑子比手快""不爱写过程"） | 故事的核心冲突，让孩子在主角身上看见自己 |
| 谁陪着看、在什么设备上 | 字号、是否需要配音、单集长度 |
| 只在家里看还是公开 | 配音接口和音乐授权的选择 |

**例子（Jasper）**：8 岁，在读《疯狂微积分》，喜欢分形、极限等抽象逻辑，但心智是 6–8 岁的孩子。
- 数学可以讲真证明，要"一眼能看出规律、但要讲清为什么永远成立"的题；
- 语气要好玩、短句、有角色；
- 主题正好是他自己的问题：学得快、懒得写过程。

## 3. 固定手法（叙事语法）

每个手法都要**跨集重复使用**。孩子一看到它，就知道接下来会发生什么。

### 3.1 颜色即意义（全片统一，不能挪用）
- **黑墨** = 世界和故事（人物、场景、主角写下的字）。
- **红笔** = 旁白的批注和吐槽，以及提问者"小问号"。红笔就像老师批改作业的笔，代表"读你东西的人"。
- **黄色荧光笔** = 这一处是关键知识。一个画面最多一两处。
- （可选）**金色** 只留给高光时刻，例如奖牌、最终答案。

### 3.2 红笔标注（标签 + 箭头）
Ben Orlin 式的一本正经吐槽，例如"书包（比他还大）""下巴（掉了）""最小的学生"。
- 用来给画面加一层旁白视角，并且制造笑点。
- 一个画面最多 2 个；停留 1.5–4 秒；箭头必须指到具体的东西上。

### 3.3 手写即思考
公式、代码、诗句都要**一笔一笔写出来**，不要凭空出现。孩子看到的是"想"的过程。
- 写错可以划掉，重写。
- 验算用红笔写在旁边，并打 ✓。

### 3.4 印章（记录时间和阶段）
每段开头，一个红色印章盖在画面中央，然后缩到右上角停住，例如"7岁 / 澳大利亚·阿德莱德"。
- 印章是时间线的锚点，孩子靠它知道"现在是几岁、第几步、哪个朝代"。
- 改编：年龄 → 年份、朝代、"第3步"、"第2关"、实验编号。

### 3.5 小问号（提问者角色）
一个红色的、问号形状的小火柴人。它代表"读你东西的人"，总是举牌问"为什么？"。
- **性格**：真心好奇，想弄懂，不是来找茬的。弄懂了就开心点头、挥手、脸红。
- **跨集弧线**：
  1. 第一次出场，追问主角"为什么是 7？"，主角觉得它烦；
  2. 主角开始写清楚，只为说服它；
  3. 主角写之前先想"小问号会问什么？"，它住进了主角脑子里；
  4. （系列结尾）主角变成了别人的小问号。
- **通用性**：数学、编程、物理、诗词都用得上。编程里可以把它叫"小 Bug"或保持原样；诗词里它问"为什么用'绿'字？"。

### 3.6 数学小知识卡（旁支知识的容器）
一张带红色"数学小知识"橡皮章的索引卡，占满画面。故事暂停，讲一个相关知识点，例如斐波那契数、黄金比与极限。
- 改名即可复用："编程小知识""诗词小知识""实验小知识"。
- 一张卡只讲一件事，15–30 秒。

### 3.7 三种写法对比
同一个问题给出三个版本：①"显然。" ②举几个例子 ③一步一步写清楚。
- 小问号分别给出 ✗、"只试了几个呀"、✓。
- 这是教"什么叫好的过程"最有效的结构，适用于写证明、写代码注释、写实验结论、赏析诗句。

### 3.8 猜想会骗人（反例时刻）
先让规律连对几次，比如圆上连线 2、4、8、16，所有人都猜 32，结果是 31。
- 这是"为什么需要证明、需要测试、需要实验"的情绪支点。
- 每个学科都能找到这样的例子，见 subjects.md。

### 3.9 尺度夸张与重复笑点
- 小个子坐在大个子中间，脚够不着地；
- 大家下巴掉了（jaw-drop 会在多集里反复出现）；
- 主角的口头禅，例如"这不是一眼就看出来了吗！"。
- 笑点要能回调：第一次出现是笑，第三次出现是"又来了"的会心。

### 3.10 图表笑话
Orlin 的招牌是用手绘图表讲情绪，例如一条"卡住曲线"：先掉进"卡住谷"，再冲上"啊哈峰"。抽象道理画成坐标图，孩子反而记得住。

### 3.11 轮到你了（互动停顿）
- 结尾出题，播放器自动停下，画面上出现"想好了吗？点这里看答案"，同时放等候音乐。
- 题目要"一眼能猜、要讲清为什么"。答案揭晓后，再让小问号追问一次"为什么"，把理由写出来。
- 纯故事集可以不放（家长可能明确说"先不用加题目"）。

### 3.12 片头、回顾、尾声、预告
- **片头卡**：系列名、第几集、本集标题，主角挥手。
- **上集回顾**：约 20 秒，用上一集最有记忆点的画面加主角口头禅。
- **尾声金句**：两句对仗的话，例如"看出来，靠聪明；写清楚，靠练习"。
- **下集预告**：下一集标题加一句旁白。

## 4. 一集的结构

默认模板约 6–8 分钟。给小一点的孩子，可以把每段缩短，做成 3 分钟。

| 段落 | 时长 | 作用 |
|---|---|---|
| 片头卡 | 5–6 秒 | 系列识别 |
| 上集回顾 | 15–20 秒 | 接上情绪和口头禅 |
| 情境（印章） | 40–80 秒 | 人物在做什么，真实细节 |
| 看出来 | 20–40 秒 | 主角一眼看出答案或规律（天赋） |
| 小问号追问 | 10–20 秒 | "为什么？""你都试过了吗？" |
| 反例或卡住 | 30–60 秒 | 猜想会骗人，或者真的卡住 |
| 方法 | 60–90 秒 | 三种写法对比 / 工具箱 / 一步一步 |
| 回收 | 40–70 秒 | 用新方法把开头的问题讲清楚（闭环） |
| 尾声金句 | 15–25 秒 | 情绪落点 |
| 下集预告 | 6–8 秒 | 钩子 |

**每一段内部**：设定 → 动作 → 反应 → 旁白红笔批注。**每个"反应"都要停够 1.5 秒**，孩子需要时间笑或者看懂。

### 1 分钟以内的单点短集
只讲一个点，比如"range 的终点不算"或"为什么是平方数"。

| 段落 | 时长 | 作用 |
|---|---|---|
| 片头卡 | 4–5 秒 | 系列识别 |
| 情境加看出来 | 10–15 秒 | 一句话交代要做什么，主角很快给出答案 |
| 出错或追问 | 8–12 秒 | 结果不对；或者小问号问"为什么" |
| 讲清楚 | 20–25 秒 | 一个画面把原因演出来：执行过程、拼图、数轴 |
| 金句（可选：轮到你了） | 5–10 秒 | 一句能复述的话 |

去掉上集回顾、小知识卡、下集预告。系列名和印章保留，它们是识别标志。

## 5. 一个系列的结构

- **外在阶梯**：看得见的进度，例如年龄 2→7→8→9→10→13 岁、铜牌→银牌→金牌、第 1 关→第 6 关、朝代先后。每集用印章标出来。
- **内在阶梯**：主角的学习方式在变，例如"看出来 → 写出来 → 写清楚 → 卡住也不怕 → 教别人"。每集往上走一级。
- **固定配角的弧线**：小问号的四个阶段（见 3.5）。
- **每集结尾埋下一集的钩子**。第 1 集片尾预告"看出来 ≠ 证出来"，第 2 集就讲它。
- **大纲要写"事实"和"演绎"两栏**，给家长确认。

## 6. 写旁白和字幕的规则

- **先写旁白，再做画面。** 旁白决定节奏，画面跟着旁白演。
- **一行字幕一个意思**：不超过 20 个汉字；超过就拆成两行，分两个时间点出现。
- **时长公式**（用 150 段真实配音拟合）：
  - 旁白（云希 +5%）：一行至少占 `0.2 秒 × 字数 + 0.8 秒`；
  - 主角（云夏）：`0.19 × 字数 + 0.95 秒`，开头停顿更长；
  - 字数的数法：按念出来的内容数（有 `say` 就数 `say`）。汉字和标点各算 1，英文字母和数字各算 0.5，空格不算。
  - 下一行在上一行结束至少 0.1 秒后开始。
  - 先用 `tools/check_timing.py` 检查，生成配音后再看 `tools/audio.py` 列出的真实超时句子。超出 0.3 秒以上的要改。
  - 播放器会等配音说完再往下走，但留足时间比让画面停住好看得多。
- **数字要写读法**：字幕显示阿拉伯数字，配音用 `say` 字段写汉字读法。
  - 年份逐位读："1983年" → "一九八三年"；
  - 算式按意思读："49" → "四十九"，"2×2" → "二乘二"。
- **角色台词**：字幕加中文引号 “……”，并标注由谁配音：主角用 `voice: 'kid'`，小问号用 `voice: 'qm'`。画面上同时出现同样文字的对白。
- **画面必须在旁白说到的时候出现**。旁白说"圆被切成两块"，这一刻画面上就是两块。
- **语气**：像一个会讲故事的大哥哥，不像老师。少用"我们要知道"，多用"来看一个有名的例子"。
- **金句要短、对仗、可以复述**。孩子能在饭桌上复述一遍，就说明成功了。

## 7. 事实与演绎的边界

- **传记和历史类**：每个"事实"都要找到出处，把出处列进大纲，包括论文、官方成绩表、本人文章、可靠的传记。
- **用户说错了要礼貌地纠正，并把真相变成更好的故事。** 例如家长以为陶哲轩"连续三年拿金牌"，实际是铜 → 银 → 金。"一年上一级"反而是更好的主线。
- **演绎**可以用来表现有记录的特点：
  - 有记录"解题后不爱检查""只写到刚好能让人相信"，就可以演一个小问号追问他的场景。
  - 但不能编造具体事件、分数、原话。
- **泛指要说成泛指**："只写答案的作业，会被红笔画满问号"是泛指大学数学的要求，不能说成"他的作业被……"。
- **人名和机构**：真实人物可以出现，但用火柴人造型，不做肖像。不画受版权保护的角色，例如芝麻街的布偶，只画电视屏幕上的字母。
- **知识类**：每个数字、每条算式都要验算，最好写一小段脚本验证，例如 31 块的区域数、1–999 中快乐数有 142 个。

## 8. 常见失误

| 失误 | 改法 |
|---|---|
| 小问号像在挑刺、说教 | 给它好奇和开心的表情，被说服时要真心高兴 |
| 知识讲成"老师念课本" | 换成角色冲突，例如"你都试过了吗？""……试了九个。" |
| 题目太简单，聪明孩子觉得无聊 | 选"一眼能猜、证明有趣"的题 |
| 一个画面同时出现三个标签加两段对白 | 每个画面只有一个焦点，其余推迟 |
| 字幕太长、配音赶不上 | 拆句，按时长公式重排 |
| 为了赶进度编造细节 | 查不到就写成泛指或删掉 |
| 做得太慢、方案太重 | 小需求（比如 10 秒样片）直接做一个；需要比较方案时，才并行做多个 |
